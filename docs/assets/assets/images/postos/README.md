Coloque aqui as imagens de cada posto usando a pasta do slug definido em data/postos.json.

Padrao esperado:
- principal.jpg = imagem principal do posto
- galeria-1.jpg, galeria-2.jpg, galeria-3.jpg = fotos extras

Exemplo:
assets/images/postos/joinha/principal.jpg
assets/images/postos/joinha/galeria-1.jpg
assets/images/postos/joinha/galeria-2.jpg
assets/images/postos/joinha/galeria-3.jpg
